# ModelListPushNotification.xlsx

## Dati

| COOP_ID | MAIL | TESTO | MESSAGGIO | IMAGE | LINK | DEEP_LINK | PROFILAZIONE | MARKETING |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

## Specifiche

| CAMPO FILE | DEFINIZIONE |
| --- | --- |
| COOP_ID | I valori accettati in questo campo sono: 1 (NovaCoop), 2 (Liguria) e 3 (Lombardia) |
| MAIL | In questo campo va inserita la mail dell'utente da notificare |
| TESTO | In questo campo va inserito il titolo della notifica che verrà visualizzata sul device dell'utente |
| MESSAGGIO | Nel caso si voglia inviare una notifica push contenente solo un messaggio bisognerà valorizzare il campo MESSAGGIO lasciando vuoti i campi IMAGE, LINK e DEEP_LINK |
| IMAGE | Nel caso si voglia inviare una notifica push contenente un'immagine con un link bisognerà valorizzare i campi IMAGE e LINK lasciando vuoti i campi MESSAGGIO e DEEP_LINK |
| LINK | Nel caso si voglia inviare una notifica push contenente un'immagine con un link bisognerà valorizzare i campi IMAGE e LINK lasciando vuoti i campi MESSAGGIO e DEEP_LINK |
| DEEP_LINK | Nel caso si voglia inviare una notifica push contenente un deep link bisognerà valorizzare il campo DEEP_LINK lasciando vuoti i campi IMAGE, LINK e MESSAGGIO |
| PROFILAZIONE | I valori accettati in questo campo sono: SI, NO. Serve a specificare se per l'utente è necessaria la verifica di accettazione della Privacy di Profilazione per l'invio della notifica |
| MARKETING | I valori accettati in questo campo sono: SI, NO. Serve a specificare se per l'utente è necessaria la verifica di accettazione della Privacy di Marketing per l'invio della notifica |
